# Tooling Options

Pricing and access change often. Verify live before asking participants to install anything.

## Chat Tools

Use ChatGPT, Claude, Gemini, or another approved chat tool for specs, context packs, briefs, teaching assets, rubrics, and critique loops with synthetic or low-risk context.

## Coding Agents

- Codex: repo-backed workflow kits, scripts, templates, verifiers, review, and automation surfaces. OpenAI documents Codex access through eligible ChatGPT plans, with limits varying by plan.
- Claude Code: terminal-first project work, memory files, slash commands, permissions, hooks, MCP, and subagents.
- GitHub Copilot: IDE and GitHub workflows. GitHub documents a Copilot Free plan, while paid signup and billing details can change.
- Gemini CLI: terminal experimentation with file tools, shell, web fetch, Google Search grounding, and MCP. The official README lists a personal free tier.

## Memory And Orchestration

- GBrain: memory and retrieval layer for approved context, chunks, embeddings, links, tags, timeline, and health checks.
- OpenClaw or Hermes-style gateways: useful when work spans sessions, messaging channels, tools, memory, approvals, and handoffs.
- Local models through Ollama or similar runners: useful for private experiments and cost control, but they still need context, tools, memory, and review gates.
