# Skill Deep Dives

## Grill Me

Use when a workflow or plan needs pressure testing. The method asks one hard question at a time, resolves each branch, and recommends a concrete answer. Workshop use: peer review selected workflows for missing inputs, risky data, vague outputs, and unowned approvals.

## Spec-Driven Work

Use before building. The spec names the user, trigger, allowed inputs, output contract, constraints, exclusions, review gate, and done criteria. It prevents polished output from replacing useful work.

## Test-Driven Work

For code, tests verify behavior. For artifacts, rubrics and validators perform the same role. Define required sections and quality checks before generating briefs, cases, checklists, or memos.

## Superpowers

Useful as a workflow discipline: brainstorm, plan, execute, verify, and finish. The institutional translation is clear: every workflow should have intent, plan, checks, and handoff.

## GStack And GBrain

GStack contributes skill routing and project learnings. GBrain contributes memory and retrieval. Together they support a skill graph: route to the right procedure, retrieve approved context, produce a durable artifact, and capture what should improve next time.

## Deep Research

Use for uncertainty, conflicting sources, vendor or tool comparisons, policy-sensitive areas, and faculty research support. The output should become a source map, context file, rubric, prompt, verifier, or pilot decision.
